# Chrono Gantt v2 仕様

## 概要

v1の仕様をベースに、タスクの並び順と表示件数を変更する。ここに記載のない項目はv1の仕様（`specs/v1/overview_ja.md`）に従う。

---

## ガントチャートビュー

### タスクの並び順（v1から変更）

- 開始日の**降順**（新しいタスクが上）
- 親子グループは親タスクの期間（自動算出した開始日）で他のタスクと並ぶ
- グループ内のサブタスクは従来通り開始日の**昇順**

### 表示件数とさらに読み込む（新規）

```
│ タスクP      │                    ██████        │  ← 新しいタスク
│ タスクO      │                ████████          │
│ ...          │                                  │  ← 15件まで表示
├──────────────┤
│ [さらに読み込む（残り N 件）]                    │
└──────────────┘
```

- 最初は**15件**まで表示する
- 親タスクとそのサブタスクはまとめて**1件**として数える（グループの途中で切れない）
- 未表示のタスクがある場合、一覧の一番下に「さらに読み込む（残り N 件）」ボタンを表示する
  - ボタンを押すと次の15件を追加表示する
  - 残りがなくなったらボタンは表示しない
  - ボタンは横スクロールしても左端に固定される
- 追加読み込み時、縦・横のスクロール位置を維持する（タイムラインの範囲が過去側に広がっても、見ていた日付がずれない）
- 読み込んだ件数は「↻ 更新」やスケール切り替えでも維持し、ビューを開き直すと15件に戻る

### タイムラインの範囲（v1から変更）

- 表示中のタスクの最小開始日〜最大終了日（前後7日の余白付き）
- 未表示のタスクはタイムラインの範囲に含めない

### ドラッグでタスクを移動（新規）

- タスクバーを**横にドラッグ**すると、期間を保ったまま日単位でタスクを移動できる（どのタイムスケールでも1日単位でスナップ）
- ドラッグ中はバーの上に移動後の期間（例: `8/10 〜 8/17`）を表示する
- ドロップすると、対象ファイルのfrontmatterの開始日・終了日（設定のフィールド名）を `YYYY-MM-DD` 形式で書き換える
  - 値がリスト形式で保存されている場合はリスト形式のまま先頭要素を書き換える
- 親タスクのバーをドラッグすると、**サブタスク全体**がまとめて移動する（親自身のfrontmatterは書き換えない）
- サブタスクを移動すると、親タスクの期間はサブタスクから再計算される
- 移動量が0日の場合は何もしない。4px未満の動きはクリックとみなし、従来通りファイルを開く
- 移動後も行の並び順はそのまま維持し、「↻ 更新」で開始日順に並び直す
- 書き込みに失敗した場合は通知を表示する

### 端をドラッグして期間を変更（新規）

- タスクバーの**左端・右端（各6px）**をドラッグすると、開始日・終了日を個別に変更できる（1日単位でスナップ）
  - バーにマウスを乗せると両端のつまみがハイライトされ、カーソルが `↔` になる
- 開始日が終了日を追い越すことはできない（開始日＝終了日の1日タスクまでは縮められる）
- ドラッグ中・保存・失敗時の挙動は「ドラッグでタスクを移動」と同じ
- **親タスクのバーにはつまみを付けない**（親の期間はサブタスクから自動算出されるため。移動のみ可能）
- 幅が20px未満のバーにはつまみを付けない（バー本体をつかめるようにするため）。短いタスクは日スケールに切り替えて変更する

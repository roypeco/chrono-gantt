# Chrono Gantt v2 仕様

## 概要

v1の仕様をベースに、タスクの並び順と表示件数を変更する。ここに記載のない項目はv1の仕様（`specs/v1/overview_ja.md`）に従う。

---

## ガントチャートビュー

### タスクの並び順（v1から変更）

- 開始日の**降順**（新しいタスクが上）
- 親子グループは親タスクの期間（自動算出した開始日）で他のタスクと並ぶ
- グループ内のサブタスクは従来通り開始日の**昇順**

### 表示件数とさらに読み込む（新規）

```
│ タスクP      │                    ██████        │  ← 新しいタスク
│ タスクO      │                ████████          │
│ ...          │                                  │  ← 15件まで表示
├──────────────┤
│ [さらに読み込む（残り N 件）]                    │
└──────────────┘
```

- 最初は**15件**まで表示する
- 親タスクとそのサブタスクはまとめて**1件**として数える（グループの途中で切れない）
- 未表示のタスクがある場合、一覧の一番下に「さらに読み込む（残り N 件）」ボタンを表示する
  - ボタンを押すと次の15件を追加表示する
  - 残りがなくなったらボタンは表示しない
  - ボタンは横スクロールしても左端に固定される
- 追加読み込み時、縦・横のスクロール位置を維持する（タイムラインの範囲が過去側に広がっても、見ていた日付がずれない）
- 読み込んだ件数は「↻ 更新」やスケール切り替えでも維持し、ビューを開き直すと15件に戻る

### タイムラインの範囲（v1から変更）

- 表示中のタスクの最小開始日〜最大終了日（前後7日の余白付き）
- 未表示のタスクはタイムラインの範囲に含めない

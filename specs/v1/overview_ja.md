# Chrono Gantt v1 仕様

## 概要

ObsidianプラグインとしてMDファイルのfrontmatterを読み取り、横スクロール対応のガントチャートを表示する。

---

## データ仕様

### スキャン対象

- プラグイン設定で指定したディレクトリ
- 対象ディレクトリ + **1階層下のサブディレクトリ**まで再帰スキャン（それ以上は含めない）

### frontmatterプロパティ

```yaml
---
start: 2026-05-01   # YYYY-MM-DD形式
end: 2026-05-15     # YYYY-MM-DD形式
status: in-progress
---
```

- 開始日・終了日のフィールド名はプラグイン設定で変更可能（デフォルト: `start` / `end`）
- 開始日・終了日のフィールドが存在しない、または形式が正しくないファイルは**スキップ**する
- `status` が未定義の場合もスキップする（`status` のフィールド名は固定）

### 親子タスク（サブタスク）

`parent` フィールド（フィールド名固定）で親タスクを指定すると、サブタスクとしてグループ化される。

```yaml
# 設計.md（サブタスク）
---
start: 2026-06-01
end: 2026-06-07
status: done
parent: XXX機能の実装   # 親タスクのファイル名（拡張子なし）。[[XXX機能の実装]] 形式も可
---
```

- 親タスクはスキャン範囲内のMDファイルで、有効な `status` を持つこと（ファイル名はスキャン範囲内で一意であること）
- 親タスクの期間は**サブタスクから自動算出**する（最小開始日〜最大終了日）。親自身の開始日・終了日はサブタスクが存在する場合は無視される
- `parent` の参照先が存在しない・無効な場合、そのタスクは通常の独立タスクとして扱う
- ネスト（サブタスクのサブタスク）は**非対応**。親として参照されているファイルの `parent` フィールドは無視される
- 有効なサブタスクが1件もない親は、自身の開始日・終了日があれば独立タスクとして表示し、なければスキップする

### ステータス値と表示色

| status 値 | 表示色 |
|---|---|
| `not-started` | グレー |
| `in-progress` | ブルー |
| `in-review` | アンバー（橙） |
| `ready-for-release` | パープル |
| `done` | グリーン |

## ガントチャートビュー

### 起動方法

- **リボンアイコン**（左サイドバー）をクリックしてメインエリアのタブとして開く（`ItemView`）

### レイアウト

```
[ ガントチャートビュー ]
┌─────────────────────────────────────────────────┐
│ [日|週|月]                          [↻ 更新]   │  ← ツールバー
├──────────────┬──────────────────────────────────┤
│ タスク名(固定)│ ← タイムライン（横スクロール） →  │
│ タスクA      │        ██████                    │
│ タスクB      │              ████████            │
└──────────────┴──────────────────────────────────┘
```

- 左カラム（タスク名）は**固定**
- タイムライン部分のみ**横スクロール**

### タイムスケール切り替え

- **日 / 週 / 月** の3段階をボタンで切り替え
- v1ではズームアニメーションなし

### タスクバーの表示

- バー上に**ファイル名（拡張子なし）**を表示
- バーを**クリック**すると対応するMDファイルをObsidianで開く

### 今日線

- 現在日を示す**赤い縦線**を常時表示

### 親子タスクの表示

```
│ XXX機能の実装 │   █████████████                  │  ← 親タスク（グループの一番上）
│   設計       │   ████                           │  ← サブタスク
│   実装       │       ██████                     │  ← サブタスク
│   デバッグ   │             ████                 │  ← サブタスク
```

- グループ内では**親タスクのバーを一番上**に表示し、その下にサブタスクを並べる
- サブタスクのタスク名はインデントし、親タスク名・親バーのラベルは太字で表示する
- 親タスクのバーはサブタスクと同じ太さで表示する（色は親自身の `status` に従う）
- グループの区切りとして最後のサブタスク行の下罫線を太くする

### タスクの並び順

- 開始日の**昇順**（上から時系列）
- 親子グループは親タスクの期間（自動算出した開始日）で他のタスクと並び、グループ内のサブタスクも開始日の昇順

### データ更新

- ツールバーの「↻ 更新」ボタンを押すと対象ディレクトリを再スキャンして再描画する
- タブの切り替え（非アクティブ→アクティブ）でも自動的に再描画される
- ファイル変更の監視による自動リフレッシュはなし

### 空の状態

- 設定未指定の場合:
  ```
  対象ディレクトリが設定されていません。
  [設定を開く]
  ```
- タスクが0件の場合:
  ```
  タスクが見つかりませんでした。
  対象: <設定されたディレクトリパス>
  ```

---

## プラグイン設定画面

| 設定項目 | デフォルト値 | 説明 |
|---|---|---|
| スキャン対象ディレクトリ | （空） | ガントチャートに表示するMDファイルの起点フォルダ |
| 開始日のフィールド名 | `start` | frontmatterで開始日を表すフィールド名。空欄の場合はデフォルト値にフォールバック |
| 終了日のフィールド名 | `end` | frontmatterで終了日を表すフィールド名。空欄の場合はデフォルト値にフォールバック |

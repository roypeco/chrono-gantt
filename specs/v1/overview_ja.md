# Chrono Gantt v1 仕様

## 概要

ObsidianプラグインとしてMDファイルのfrontmatterを読み取り、横スクロール対応のガントチャートを表示する。

---

## データ仕様

### スキャン対象

- プラグイン設定で指定したディレクトリ
- 対象ディレクトリ + **1階層下のサブディレクトリ**まで再帰スキャン（それ以上は含めない）

### frontmatterプロパティ

```yaml
---
start: 2026-05-01   # YYYY-MM-DD形式
end: 2026-05-15     # YYYY-MM-DD形式
status: in-progress
---
```

- `start` / `end` が存在しない、または形式が正しくないファイルは**スキップ**する
- `status` が未定義の場合もスキップする

### ステータス値と表示色

| status 値 | 表示色 |
|---|---|
| `not-started` | グレー |
| `in-progress` | ブルー |
| `in-review` | アンバー（橙） |
| `ready-for-release` | パープル |
| `done` | グリーン |

## ガントチャートビュー

### 起動方法

- **リボンアイコン**（左サイドバー）をクリックしてメインエリアのタブとして開く（`ItemView`）

### レイアウト

```
[ ガントチャートビュー ]
┌─────────────────────────────────────────────────┐
│ [日|週|月]                          [↻ 更新]   │  ← ツールバー
├──────────────┬──────────────────────────────────┤
│ タスク名(固定)│ ← タイムライン（横スクロール） →  │
│ タスクA      │        ██████                    │
│ タスクB      │              ████████            │
└──────────────┴──────────────────────────────────┘
```

- 左カラム（タスク名）は**固定**
- タイムライン部分のみ**横スクロール**

### タイムスケール切り替え

- **日 / 週 / 月** の3段階をボタンで切り替え
- v1ではズームアニメーションなし

### タスクバーの表示

- バー上に**ファイル名（拡張子なし）**を表示
- バーを**クリック**すると対応するMDファイルをObsidianで開く

### 今日線

- 現在日を示す**赤い縦線**を常時表示

### タスクの並び順

- `start` 日付の**昇順**（上から時系列）

### データ更新

- ツールバーの「↻ 更新」ボタンを押すと対象ディレクトリを再スキャンして再描画する
- タブの切り替え（非アクティブ→アクティブ）でも自動的に再描画される
- ファイル変更の監視による自動リフレッシュはなし

### 空の状態

- 設定未指定の場合:
  ```
  対象ディレクトリが設定されていません。
  [設定を開く]
  ```
- タスクが0件の場合:
  ```
  タスクが見つかりませんでした。
  対象: <設定されたディレクトリパス>
  ```
